--------------------------------------------------------------------------------
COLUMN: SANCTIONED_LMT
--------------------------------------------------------------------------------
Original logic (verbatim):

IIF(PRD_CODE='P2',RELEASED_AMOUNT,
IIF(NOT ISNULL(Lkp_PROC_DTE),Lkp_AC_AUTH_LMT,
                IIF(IN(SYS_CODE,'RB','FM') AND PRD_TYP_CODE = 'AST' AND
                                                NOT IN (MI_PRD_CODE,'BLK', 'FLOORSTK'),Ac_Auth_Lmt,
                                IIF(SYS_CODE='TF',TF_Rcy_Auth_Lmt_v,
                                                IIF(SYS_CODE='TS',TS_Rcy_Auth_Lmt_v)
                                                )
                                )
                )
)

Decision tree (priority order):
  1. PRD_CODE='P2'                                              -> RELEASED_AMOUNT
  2. lookup matched (NOT ISNULL Lkp_PROC_DTE)                   -> Lkp_AC_AUTH_LMT
  3. SYS_CODE in (RB,FM) AND PRD_TYP_CODE='AST'
     AND MI_PRD_CODE not in (BLK,FLOORSTK)                      -> AC_AUTH_LMT
  4. SYS_CODE='TF'                                              -> TF_Rcy_Auth_Lmt_v
  5. SYS_CODE='TS'                                              -> TS_Rcy_Auth_Lmt_v
  6. otherwise (innermost IIF has no false branch)              -> NULL

Fields IN the DWH view (V_T_MTH_AC_DTL):
  PRD_CODE (22), SYS_CODE (36), PRD_TYP_CODE (21), MI_PRD_CODE (23),
  AC_AUTH_LMT (28)

Fields NOT in the DWH view - SOURCE TO CONFIRM:
  RELEASED_AMOUNT        branch 1 (PRD_CODE='P2'). Which table / column?
  Lkp_PROC_DTE +         branch 2 lookup. Which table, join key, month filter?
  Lkp_AC_AUTH_LMT        Returns that table's AC_AUTH_LMT - a DIFFERENT field
                         from the DWH AC_AUTH_LMT used in branch 3.
  TF_Rcy_Auth_Lmt_v      branch 4 (SYS_CODE='TF'). TF auth limit in reporting
                         currency. Source, and is RCY conversion already done?
  TS_Rcy_Auth_Lmt_v      branch 5 (SYS_CODE='TS'). Same questions for TS.
